🎨 Convert SVG to PWA Icons

Instructions:
  1. Click "Load SVG" to load the logo
  2. Click "Generate 192x192" to create icon-192.png
  3. Click "Generate 512x512" to create icon-512.png
  4. Right-click each canvas and "Save image as..." to save the PNG files
  5. Save them in the frontend/public/icons/ directory
